# SuicideByStar website

Adding an episode, regular or best albums of the year, is documented in `docs/adding-a-podcast.md`.

Open Graph images have gotchas documented in `docs/og-images.md`; read it before changing `src/pages/og/`, `src/lib/og.ts`, `site` in `astro.config.mjs`, or the `path`/`title` frontmatter of a post.

## Commits and pull requests

Commit subjects are lowercase and start with an imperative verb: `add new post`, `fix bluesky link`, `upgrade to node 24`.

Pull request titles use the same format: `add guide for adding a podcast`.
